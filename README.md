# DNStoHOSTS

**DNStoHOSTS** — мощная и стильная утилита для Android, предназначенная для массового резолвинга доменных имён в IP-адреса с использованием протокола **DNS over HTTPS (DoH)**.

Приложение включает **встроенный редактор конфигурации**, позволяющий управлять всеми файлами напрямую.

---

## ✨ Особенности

- **🚀 DNS over HTTPS (DoH)**  
  Безопасный и быстрый резолвинг через порт 443 с возможностью его изменения.

- **⚡ Бинарный протокол**  
  Использование `application/dns-message` (RFC 1035) для максимальной скорости и экономии трафика.

- **📝 Встроенный редактор**  
  Редактирование списков доменов и настроек прямо в приложении без сторонних файловых менеджеров.

- **🎨 Современный UI**
  - Deep Dark Theme  
  - Плавные анимации и прогресс-бары  
  - Адаптивная иконка (Monet / Themed Icon)

- **📋 Работа с буфером обмена**  
  Быстрое копирование результатов и конфигураций.

- **🤖 Автоматизация**  
  При отсутствии входных файлов приложение создаёт их автоматически с примерами.

## 📱 Интерфейс и функции

### Главный экран

- **Лог событий** — отображает процесс резолвинга в реальном времени  
- **Статус** — цветовая индикация процесса:
  - Серый — ожидание  
  - Синий — работа  
  - Зелёный — завершено
- **Кнопки управления** — `Start`, `Stop`, `Clear Log`
- **Кнопки редактора** — быстрый доступ к `Input`, `Output` и `Settings` внизу экрана

### Встроенный редактор

При нажатии на кнопку файла открывается полноэкранный редактор со следующими возможностями:

- **Save** — сохранить изменения на диск  
- **Copy** — скопировать всё содержимое в буфер обмена  
- **Clear** — очистить поле  
- **Reset** *(только для Settings)* — сброс настроек на стандартные (`dns.google`)

## 📂 Файловая система

Приложение работает в собственной директории:

```
/storage/emulated/0/Android/data/com.dnstohosts.app/files/
```

### 1. `input.txt` — входные данные

Список доменов для обработки.  
Если файл отсутствует, он создаётся автоматически с примером.

```text
# Google
google.com
```

---

### 2. `settings.txt` — конфигурация

Настройки подключения к DoH-серверу.

```ini
adress=dns.google
port=443
ipv4=true
ipv6=false
```

---

### 3. `output.txt` — результат

Готовый список IP-адресов и доменов, пригодный для использования в файлах `hosts`.

```text
# Google
142.250.1.100 google.com
142.250.1.101 google.com
```

- **Язык:** Kotlin

- **Сеть:** OkHttp 4 (HTTP/2, бинарные потоки)  
- **Асинхронность:** Kotlin Coroutines  
- **Сборка:** Gradle + GitHub Actions (CI/CD)
