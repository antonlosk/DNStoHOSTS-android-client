# DNStoHOSTS

**DNStoHOSTS** — мощная и минималистичная утилита для Android, предназначенная для массового резолвинга доменных имён в IP-адреса через протокол **DNS over HTTPS (DoH)**.

Приложение выполнено в современном стиле **Material 3**, поддерживает динамические иконки (Monet) и использует эффективные бинарные DNS-запросы (RFC 1035) для максимальной производительности и экономии трафика.

## ✨ Особенности

* **DNS over HTTPS (DoH):** Безопасный резолвинг через HTTPS (порты 443/8443).
* **Бинарный протокол:** Используется `application/dns-message` вместо медленного JSON API.
* **Массовая обработка:** Чтение списка доменов из файла и генерация готового `hosts`-файла.
* **Поддержка IPv4 и IPv6:** Гибкий выбор типов DNS-записей (A и AAAA).
* **Современный UI:**
  * Полная поддержка тёмной темы (Deep Black).
  * Адаптивная иконка с поддержкой системных цветов (Monet / Themed Icon).
* **Логирование:** Подробный лог выполнения операций в реальном времени.

## 📂 Работа с файлами

Приложение работает с файлами во внутренней памяти устройства.

**Путь:**  
`/storage/emulated/0/Android/data/com.dnstohosts.app/files/`

При первом запуске приложение автоматически создаёт необходимые файлы с настройками по умолчанию.

### 1. `input.txt` — список доменов

Содержит домены, которые необходимо отрезолвить. Поддерживаются комментарии (`#`).

```
# Google
google.com
```

### 2. `settings.txt` — настройки

Файл конфигурации DNS-сервера.

```
address=dns.google
port=443
ipv4=true
ipv6=false
```

* `address` — хост DoH-сервера (например: `dns.google`, `cloudflare-dns.com`)
* `port` — порт подключения (обычно `443`)
* `ipv4` / `ipv6` — `true` или `false`, определяет типы IP-адресов для поиска

### 3. `output.txt` — результат

Файл с результатом резолвинга в формате, готовом для использования в `hosts`.

```
# Google
64.233.165.138 google.com
```

## 🛠 Технический стек

* **Язык:** Kotlin
* **UI:** Jetpack Compose (Material 3)
* **Сеть:** OkHttp 4 (поддержка HTTP/2)
* **Архитектура:** Single Activity, Coroutines
* **Сборка:** Gradle + GitHub Actions (CI/CD)

## 📥 Установка и сборка

### Скачать APK

Актуальные версии доступны в разделе [Releases](../../releases).  
Сборки создаются автоматически при каждом обновлении репозитория.

### Сборка из исходников

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/yourusername/DNStoHOSTS.git
   ```
2. Откройте проект в Android Studio.
3. Выполните сборку:
   ```bash
   ./gradlew assembleRelease
   ```
